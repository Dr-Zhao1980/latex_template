# LaTeX 模板集

收集自己觉得好用的 LaTeX 模板，方便学习、写作与复用。每个模板独立维护，后续会继续加入更多类型。

## 已收录模板

| 模板 | 适用场景 | 编译方式 |
| --- | --- | --- |
| [LaTeX 学习笔记模板](LaTeX_学习笔记模板/) | 中文学习笔记、专题报告、论文初稿 | XeLaTeX + latexmk + BibTeX |

当前模板提供论文式封面、中英文摘要、目录、七章正文、参考文献及四个附录。正文只有简短的示例文字和必要的公式、图表示例，可直接替换。

## 快速使用



```sh
git clone https://github.com/Dr-Zhao1980/latex_template.git
cd latex_template/LaTeX_学习笔记模板
latexmk main.tex
```

安装 TeX Live 后，在模板目录运行上述编译命令，结果位于 `build/main.pdf`。Windows 用户也可以双击模板内的 `setup-latex.bat` 完成环境检查与首次编译。

使用 VS Code 时，直接打开相应模板目录，并安装 LaTeX Workshop。

## 仓库结构

```text
latex_template/
├── README.md                       # 模板目录与仓库说明
├── docs/                           # 编译、语法与维护指南
└── LaTeX_学习笔记模板/
    ├── README.md                   # 当前模板的使用说明
    ├── main.tex                    # 主文件与填写信息
    ├── chapters/
    │   ├── 正文/                   # 摘要与七章正文
    │   └── 附录/                   # 四个附录
    ├── config/note-style.sty        # 集中管理排版
    ├── media/                      # 自行添加插图
    ├── references.bib              # 一条文献引用示例
    ├── .vscode/                    # 编译配置与代码片段
    ├── latexmkrc                   # 命令行编译规则
    ├── setup-latex.bat
    └── setup-latex.ps1

```

正文按“绪论—基础理论—模型建立—方法与推导—结果与分析—讨论与扩展—总结与展望”组织；附录使用“附录一、附录二、附录三、附录四”。结构参考原笔记的七个正文文件和四个附录。原始笔记在仓库外单独归档，不随模板发布。

这是通用模板，采用常见论文层级与编号方式；提交到具体学校或期刊前，请按其要求调整版式。

## 后续收录约定

每个新模板在仓库根目录建立独立目录，附上 README、来源及许可信息，并在上方模板表中补充一行。模板应可独立编译，使用相对路径，避免依赖其他模板或本机设置。

编译缓存、日志和自动生成的 `main.pdf` 不提交。PDF 插图可以提交；需要预览时，可放在对应模板的 `preview/` 目录。

收录第三方模板时，保留原作者、来源与许可信息。
