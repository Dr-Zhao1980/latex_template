# 添加新模板

仓库按“一个模板一个独立目录”维护。学习笔记模板是首个条目，后续模板与其平级，不应嵌入它的章节或配置目录。

## 建议结构

```text
LaTeX_新模板名称/
├── README.md               # 用途、入口、依赖、编译与修改方法
├── main.tex                # 或在 README 中说明其他入口名
├── chapters/               # 按实际需要拆分正文和附录
├── config/                 # 样式文件
├── media/                  # 图片，包括 PDF 插图
├── references.bib          # 有文献需求时提供
└── latexmkrc               # 此模板独立的编译规则
```

轻量模板可以只有主文件和 README，无需为了凑齐结构增加空目录。

## 收录步骤

1. 将新模板放到仓库根目录下，使用能说明用途的目录名。
2. 记录原作者、来源链接和许可证，保留第三方模板要求的声明。个人编写内容也应明确使用条件。
3. 在模板 README 说明：适用场景、主文件、编译引擎、依赖、编译命令、输出位置和需要修改的字段。
4. 使用相对路径。各模板独立保存配置，不依赖其他模板，也不写死本机盘符、用户名或系统字体。
5. 完整编译，检查目录、正文、附录、图表、参考文献和链接。若需要预览，放入模板自己的 `preview/` 并在 README 链接。
6. 更新 [仓库首页的模板目录](../README.md)，只登记已经加入的模板。
7. 检查 Git 变更，提交并推送到仓库。

仓库的 `.gitignore` 统一忽略 `build/`、日志和自动生成的 `main.pdf`。PDF 插图与精选预览允许提交；其他入口名生成的 PDF 可在对应模板自己的 `.gitignore` 中补充忽略规则。
