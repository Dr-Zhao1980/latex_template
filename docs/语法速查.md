# 日常 LaTeX 速查（XeLaTeX）

这份手册从原笔记的 `latex常用语法.md` 整理、勘误而来。所有示例在本模板中均可使用。

## 文档层级

```latex
\chapter{第一个主题}
\section{课程要点}
\subsection{某个问题}
\paragraph{一句总结} 正文……
```

一个主题拆成一个 `.tex` 文件，正文放在 `chapters/正文/`，补充推导放在 `chapters/附录/`。
在 `main.tex` 中使用 `\input{chapters/正文/文件名.tex}`；附录在 `\noteappendix` 后载入。
两层目录中的子文件可加 `% !TeX root = ../../main.tex`，让编辑器定位主文档。

## 文字、强调、换段

- 空一行：换段；`\\`：只在表格/对齐等需要强制换行的位置使用。
- `\textbf{加粗}`、`\emph{强调}`、`\textcolor{red}{红色}`。
- `\term{概念}`、`\highlight{关键结论}`：使用本模板的主题色。
- `\begingroup\small ... \endgroup`：只在局部改变字号，不污染后文。
- `\noterule`：分隔线；`\vspace{0.5em}`：小段留白。
- 特殊符号 `# $ % & _ { }` 需要写作 `\# \$ \% \& \_ \{ \}`。
- 文本中的反斜线写作 `\textbackslash{}`；`\\` 不是转义反斜线。

## 数学公式

```latex
行内：\( a^2+b^2=c^2 \)
无编号：\[ E=mc^2 \]
有编号：
\begin{equation}\label{eq:energy}
  E=mc^2
\end{equation}
正文引用：式 \eqref{eq:energy}
```

推荐 `\[ ... \]`，**不要**用 `$$ ... $$`（与 LaTeX 显示公式机制不完全兼容）。

多行对齐：

```latex
\begin{align}
  a &= b+c,\\
  d &= e+f.
\end{align}
```

向量、矩阵、算子的维度约定：

```latex
\dimvec{v}{3}     % \vec{v}_{3\times1}
\dimmat{A}{3}{3}  % \bm{A}_{3\times3}
\dimop{L}{5}{5}   % \mathsf{L}_{5\times5}
\pder{u}{t}       % \frac{\partial u}{\partial t}
\oder{x}{t}       % \frac{\mathrm{d}x}{\mathrm{d}t}
```

## 定理、问题框与列表

```latex
\begin{definition}[重要定义]
  这里写定义。
\end{definition}
\begin{theorem}\label{thm:demo}
  这里写结论。
\end{theorem}
\begin{proof}
  这里写证明。
\end{proof}
\begin{noteinfo}[课堂重点] ... \end{noteinfo}
\begin{notewarning}[易错点] ... \end{notewarning}
\begin{notequestion}[待思考] ... \end{notequestion}
\begin{itemize}
  \item 第一条
  \item 第二条
\end{itemize}
```

## 交叉引用、图片、表格

```latex
\label{sec:method}                 % 建议在标题后给标签
\ref{sec:method}                   % 编号引用
\eqref{eq:energy}                  % 带括号的公式编号
\href{https://www.ctan.org}{CTAN}  % 超链接

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.7\linewidth]{your-figure.png}
  \caption{图题}\label{fig:demo}
\end{figure}
```

表格建议 `booktabs + tabularx`，参看 [结果与分析示例](../LaTeX_学习笔记模板/chapters/正文/05-结果与分析.tex)。

## 参考文献

1. 在 `references.bib` 里加入文献条目。
2. 在正文中用 `\cite{文献键}`。
3. 保持 `main.tex` 中的 `\notebibliographytrue`（当前默认已开启）。
4. 用 `latexmk` 编译，自动运行 BibTeX。

VS Code 的片段快捷输入：`nchapter`、`nalign`、`neq`、`nbox`、`nq`、`nfig`、`nvec`、`nmat`。
