# 原笔记结构与模板对应表

模板参考原学习笔记的七个正文文件和四个附录组织结构。原笔记在仓库外单独归档；发布的模板使用通用标题和简短示例。

以下原文件名来自原工程的 `chapters/`；新文件路径相对于 `LaTeX_学习笔记模板/`。

正文和附录分别存放在 `chapters/正文/` 与 `chapters/附录/`。文件名使用数字前缀，输出显示“附录一”至“附录四”；公式、图表加“附”前缀，避免与正文编号混淆。

## 排版整理

- 每个正文或附录文件独立声明一个 `\chapter`；其下按 `\section`、`\subsection` 组织。
- 参考文献在正文之后，四个附录在 `\noteappendix` 之后载入。
- 主文件中声明顺序，样式集中到 `config/note-style.sty`，编号与引用自动生成。
- 发布目录只保留模板源码、配置及使用文档。

如需将自己的旧笔记填入模板，复制需要的段落、图片及文献条目即可；合并时检查标签和文献键重名，再完整编译。
