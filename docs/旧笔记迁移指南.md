# 原笔记结构与模板对应表

模板延续原笔记的正文与附录分区。每章只保留最小示例，按实际学习内容填写即可。

## 正文

| 文件 | 简短示例 |
| --- | --- |
| `01-章节1.tex` | 章、节、小节与普通文字 |
| `02-章节2.tex` | 文字和参考文献 |
| `03-章节3.tex` | 定义与符号 |
| `04-章节4.tex` | 矩阵公式与公式编号 |
| `05-章节5.tex` | 定理与证明 |
| `06-章节6.tex` | 表格和图片 |
| `07-章节7.tex` | 补充记录与附录引用 |
| `08-章节8.tex` | 问题与后续计划 |

文件位于 `LaTeX_学习笔记模板/chapters/01-正文/`，标题可替换为课程主题。章节从 1 开始编号，不包含摘要或论文固定章节。

## 附录

| 原笔记的作用 | 模板文件 |
| --- | --- |
| 守恒量与通量速查 | `附录1-符号与关系速查.tex` |
| Hugoniot 曲线详细推导 | `附录2-补充推导.tex` |
| 拓展模型推导 | `附录3-补充材料.tex` |
| 参数与能量分解说明 | `附录4-参数说明.tex` |

附录位于 `chapters/02-附录/`，保留“附录一、二、三、四”的编号。旧笔记的具体内容另行归档，不随模板载入。

迁入自己的笔记时，复制需要的段落、图片和文献条目，检查标签重名，再完整编译。
